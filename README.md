# Telegram Username Search Bot

Бот с inline-меню для поиска возможных Telegram-юзернеймов. Публичная проверка t.me — предварительная, не гарантия регистрации.

## Запуск

1. Виртуальное окружение `.venv` уже создано; активируйте его: `.venv\Scripts\Activate.ps1`
2. Если переносите проект на другой ПК: `py -3.12 -m venv .venv`
3. Установите зависимости: `pip install -r requirements.txt`
4. Скопируйте `.env.example` в `.env` и вставьте токен от BotFather в `BOT_TOKEN`. Номер телефона, MTProto-сессия, `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` **для поиска не требуются**.
5. Запустите: `.venv\Scripts\python.exe bot.py`

Команды: `/start`, `/help`, `/cancel`.

## Как работает фильтр

- пустой фильтр — разные слова и звучные псевдослова;
- `?a?er` — `?` означает любую латинскую букву;
- `-xq` — исключить буквы `x` и `q`;
- `a,e -x` — обязательно использовать `a` или `e`, исключить `x`.

## Параллельные поиски и проверка

- Бот использует **один Bot API-токен** и публичные страницы **t.me**. Пользователям не требуется подключать свои телефоны или аккаунты Telegram; сам поиск не отправляет запросы на Fragment.
- У каждого Telegram ID может идти только один поиск одновременно, **разные пользователи ищут параллельно**. Общий семафор ограничивает до 8 одновременно выполняемых HTTP-запросов, чтобы не перегружать Telegram.
- Если публичная страница имени не найдена, бот показывает статус **«возможно доступен»**. Это **не доказательство свободности**: имя может быть зарезервировано Telegram или недоступно для регистрации.
- Если t.me отвечает ошибкой/429 или нет уверенного результата, бот не объявляет имя свободным. Если ни один вариант не удалось проверить из-за технического сбоя, бесплатная попытка возвращается.
- Результаты одного пользователя не повторяются в последующих проверках; история хранится в SQLite.

## Логи и диагностика

- `logs/bot.log` — запуск, поиск, ошибки и предупреждения.
- `logs/errors.log` — ошибки и полные трассировки исключений.
- Каждый лог ротируется при достижении 2 МБ, сохраняются три предыдущих файла. Токены бота берутся из `.env` и не выводятся в лог.
- Ошибка `Bad Request: message is not modified` при повторном выборе параметра не останавливает бот.
- Если публичная проверка недоступна, бот сообщает об этом и не выдаёт ложные результаты.

**Оценка рыночной стоимости** по желанию пользователя остаётся отдельной функцией: она обращается к публичным данным Fragment без подключения кошелька или номера телефона.

## Лимиты поиска

- **Free:** 1–2 свободных юзернейма за один поиск; максимум **3 запуска поиска за календарные сутки**.
- **Premium / администраторы:** 1–15 результатов за запуск, без суточного лимита.
- **Free и Premium:** после окончания поиска действует пауза **60 секунд**. **Ultra** работает без этой паузы и без суточного лимита.
- Бесплатные 3 запуска обновляются **в 00:00 по Киеву**. У каждого Telegram ID свой счётчик; данные сохраняются в SQLite `bot.db` и не сбрасываются перезапуском.
- Считается **запуск поиска**, а не количество найденных свободных имён. Например, три поиска по одному или два имени — это одинаково три запуска. Если проверка состоялась, но подходящих имён не нашлось, запуск учитывается. Если все HTTP-проверки завершились технической ошибкой, попытка возвращается. Отклонённые попытки во время паузы и при исчерпанном лимите не списываются.
- Настройки доступны через **🔎 Поиск → 🔢 Количество**; остаток бесплатных запусков можно посмотреть в **👤 Профиль**. Если имена закончились до фактической проверки, лимит не расходуется.

## Оценка Telegram-юзернейма

1. В главном меню нажмите **💰 Оценить юзернейм**.
2. Отправьте юзернейм, например `@hexora`, или ссылку `https://t.me/hexora`.
3. Бот ищет публичные завершённые продажи похожих юзернеймов на `https://fragment.com/` и выдаёт PNG-карточку: ориентировочную стоимость в TON, алгоритмическую ценность `/100`, ссылки на аналогичные сделки.

Стоимость рассчитывается **только при наличии трёх и более похожих завершённых продаж** за последние три года. Диапазон в TON — ориентир по другим именам, не гарантированная цена или подтверждение права продажи вашего имени. Если данные Fragment недоступны или их мало, бот не выдумывает цену и показывает только алгоритмическую ценность. Fragment может изменить свою публичную HTML-разметку. Авторизация на Fragment и подключение кошелька не требуются.
